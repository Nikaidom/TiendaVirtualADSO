# EcoMarket - Tienda Virtual

## Objetivo de la tienda
Ofrecer una alternativa accesible y transparente de consumo responsable, conectando a los consumidores con productos ecológicos, locales y de comercio justo para reducir el impacto ambiental diario.

## Funciones Principales
1. **Catálogo filtrable de productos sostenibles:** Permite a los usuarios buscar artículos según criterios específicos como huella de carbono, materiales reciclados, origen local y certificaciones orgánicas.
2. **Calculadora de impacto ambiental:** Muestra en tiempo real el ahorro estimado de plástico, agua y emisiones de CO2 generado por las compras realizadas por cada usuario en su perfil.
